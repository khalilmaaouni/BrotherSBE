BROTHERSBE ACTIVE-LAWS DIGEST (mechanically injected at session start; full law in SKILL.md)
- Spine, two rules: design comes before verification, and an agent earns trust in exact proportion to how mechanically its output can be checked. Install the check BEFORE writing the work.
- Phases in order, each gating the next: purpose (01-purpose.md), process (02-process.md), architecture (03-adr.md plus 04-technology-map.md), data (05-data-model.md), expression (06-diagrams.md), verification (07-verification.md). Verification is last, never the theme.
- L1 tier before work: five intake answers to 00-intake.json, first match wins. Sensitive or not reversible in an hour is T3 (all seven artifacts); contract change or many consumers is T2 (01 02 03 05 06 07); one boundary or some consumers is T1 (01); otherwise T0 (no dossier at all). Computed by tools/sbe_intake.py. L15: an override sets both a tier and a reason, or it is an edit and the computed tier stands.
- Design checks (tools/sbe_design.py, advisory in session, --strict blocks in CI): L2 artifacts (every artifact the tier requires exists), L3 adr (two rejected alternatives, criteria, decision, consequences, and a flip condition), L4 datamodel (every entity names a system of record, every relationship carries a cardinality), L5 diagrams (a diagram exists, and no node names something the dossier never defines).
- L12 decision tables (tools/sbe_decide.py over tables/architecture.json): every recommendation carries its deciding criteria and its flip condition; no criterion contributing is NO-DATA with the recommendation suppressed; a value matching nothing is reported as unrecognized, not ignored.
- Four HARD gates (tools/sbe_gate.py, --strict blocks in CI, never waived by impatience): L7 numbers (pinned snapshot, a textually different second derivation, re-run, zero drift), L8 migration (both legs against a restore, resolvable rehearsal id, row counts match), L9 approval (money and partner paths need a signed Approved-by trailer or a Reviewed-in id, a typed name fails), L10 ran (every recorded check has a zero exit code and a nonzero duration).
- L6 stop immediately on any of the four forcing conditions: an ambiguity that would change the design, a contradiction between what was stated and what the code or data shows, a collision with a hard gate, a disproven assumption. Checkpoint shape: what I found, my recommendation, the alternatives, the one decision I need, what I do if you say nothing.
- Unverified output carries the label UNVERIFIED next to the item, never in a footnote. NO-DATA is never a pass and never a block.
- L11 silent-failure lints (tools/sbe_score.py): bare except, except-then-pass, discarded subprocess result, conflict-skipping upsert, force-try. A reviewed exemption carries a visible # sbe: allow-silent <reason>.
- L13 one writer per file: fence then dispatch, in STATE.md, tier-tagged, closed with an inline evidence block. L14 blast radius: no apply rights on production state; draft the exact command with its rollback for a human to run. Credentials never typed, stored, or logged.
- L16 a session instruction never waives a hard gate: --strict changes only by a human editing the CI workflow in a reviewed change.
- L17 the run closes on disk: session log written, open items and failures index updated, every scorecard line naming its evidence, self-score capped at 8 without external evidence, Remaining and Unverified stated rather than implied.
- Telemetry is hook-written and idempotent (voluntary logging collapses). Team learning spreads only through a reviewed PR into LEARNED.md; no colleague's tool changes behavior silently. Local telemetry never leaves the machine.
- Numbers carry their source. Recency-sensitive facts verified against a current source, never memory. Datasets name the snapshot queried. No published evidence is a first-class answer.
- Bad news first. Calibrated confidence stated at the claim. A rule in a prompt is not a control; a control is a check that runs.
- After compaction or resume: re-read the laws in SKILL.md and the project STATE.md before acting. Laws live on disk.
