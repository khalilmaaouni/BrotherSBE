# The worked estate
This is the book's running example: a tiny nightly pipeline plus a read API, real enough to run and small enough to hold in one look.
The book owns this folder; every terminal block in the book that touches it is re-executed here, never typed from memory.
Run `python3 pipeline.py --date 2026-07-01` then `python3 test_estate.py`.
`orders.csv` and `daily_totals.json` are generated by the pipeline on each run, so both are gitignored rather than committed.
